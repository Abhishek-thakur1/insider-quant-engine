Decisions for you (proposed defaults)

Accent and theme

One calm blue accent on a dark base, with a light theme available.

Keep /classic for

2 weeks after the new dashboard goes live, then remove it with your OK.

Learn visibility

An unlinked route for now. There's no login; adding one belongs to the mobile-backend plan.

Phone priority

Today, Positions, Signals and Health in the bottom navigation, with the rest under "More".

  • The signals feed, funnel, health and watchlist heat need new read-only API data. That's a request for you, not something I'd change.
  • Defects found in the current dashboard are listed in the audit, the main one being invented stop and target values in the trade modal.
  • Budget: today's JS bundle is 766,549 B. Charts and Learn would be lazy-loaded, with the size reported at every stage.
